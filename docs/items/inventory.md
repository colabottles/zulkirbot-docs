# Inventory

Shortcut Keys: `!i`, `!bag`, `!items`.

| Command | Description |
| --- | --- |
| `!inventory` | Posts a link to your inventory page. Duplicate items are stacked and shown with a count. |
| `!equip [item]` | Equip an item from your inventory. |
| `!unequip [slot]` | Unequip an item from a slot. |
| `!unequip all` | Unequip all non-cursed items at once. |
| `!use [item]` | Use a scroll or potion. |
| `!potion` | Drink a potion from your inventory. |
| `!drop [item]` | Permanently discard an item. |

## The Inventory Page

The link posted by `!inventory` opens a web page showing your full inventory — equipped items and bag contents separately, with duplicate items stacked and counted.

Each item shows its rarity by color:

| Rarity | Color |
| --- | --- |
| Common | White |
| Uncommon | Green |
| Rare | Blue |
| Epic | Purple |
| Legendary | Orange |
| Mythic | Red |

Items also show their stat bonus with a label (e.g. `+5 def`, `+3 atk & dmg`) based on what the item actually grants — not just its equipment slot.

> [!WARNING]
> You cannot drop or sell equipped or cursed items.
