# Selling Items

## !sell [item]

Sell an unequipped item for gold.

| Rarity | Base Price |
| --- | --- |
| Common | 10 gp |
| Uncommon | 30 gp |
| Rare | 60 gp |
| Epic | 100 gp |
| Legendary | 150 gp |
| Mythic | 200 gp |

> [!TIP]
> Rare, Epic, Legendary, and Mythic items roll a d100 on sale. Roll **75 or higher** and you get **double** the price!

## !sell all

Sell all unequipped, non-cursed items at once.

::: note
📝 `!sell all` skips items whose curse has been revealed. Unidentified cursed items are sold as normal.
:::
