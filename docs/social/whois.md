# !whois

Look up another player's character class and level.

## Usage

!whois [username]

## Example

!whois neutralagent
→ neutralagent (Steve's Pal) is a Level 14 Rogue.

## Notes

- Works on any player with an active character.
- Returns class and level only — for full stats use `!status [username]`.
- 5 second cooldown.
