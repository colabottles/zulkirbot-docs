# The Tavern

| Command | Description |
| --- | --- |
| `!tavern` | Welcome message with available tavern commands. Shortcut key: `!t` |
| `!drinks` | Browse the full drinks menu. from 8 gp to 20 gp in cost. Shortcut key: `!dr` |
| `!meals` | Browse the full meals menu. Meals restore HP immediately. You cannot eat during a tavern fight. |
| `!tavern drink [name]` | Order a drink. Buffs last for your next fight. Some named drinks don't have any benefit to them. |
| `!tavern meal [name]` | Order a meal to restore lost HP. The amount varies by meal (5–14 HP). You cannot order a meal if you are already at full HP. |
| `!barkeep` | Hear from the barkeep. Available after your first purchase. 30 second cooldown. |
| `!rumour` | Hear a rumour from a fellow patron. Available after your first purchase. 30 second cooldown. |
| `!gamble [amount] [number 0-36] [red/black]` | Spin the roulette wheel. Exact number pays 35:1, color match pays 1:1. 0 is green and beats everything. |
