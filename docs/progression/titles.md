# Titles

Titles are earned by slaying monsters, completing campaigns, and defeating invasion bosses.

`!title Rat` will find `Rat Catcher` if you've earned it.

| Command | Description |
| --- | --- |
| `!titles [@user]` | View all earned titles. Your active title shows with a ★. |
| `!title [name]` | Set your active title to display in `!status`. |
| `!title clear` | Remove your active title. |
