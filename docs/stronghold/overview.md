# Stronghold Overview

A stronghold is a personal base of operations tied to your character. Build it, upgrade it, defend it, and use it to gain advantages in combat and exploration.

::: warning
Strongholds are lost on permadeath. When your character dies, your stronghold is overrun and destroyed.
:::

## Stronghold Types by Class

Your class determines the type of stronghold you can build.

| Type | Classes | Tiers |
| --- | --- | --- |
| Martial | Fighter, Barbarian, Paladin, Ranger, Monk, Sacred Fist, Dark Hunter, Dragon Lord | Outpost → Keep → Castle → Fortress → Citadel |
| Arcane | Wizard, Sorcerer, Warlock, Wild Mage, Dragon Disciple | Wizard's Tower → Arcane Spire → Tower of Power → Tower of Dominion → Tower of Eternity |
| Divine | Cleric, Druid, Favored Soul, Dark Apostate, Blightcaster | Shrine → Temple → Cathedral → Sanctum → Divine Bastion |
| Shadow | Rogue, Arcane Trickster | Hideout → Safehouse → Thieves Den → Shadow Guild → Underworld Citadel |
| Bardic | Bard, Stormsinger | Waystation → Inn → Grand Hall → Concert Hall → Legendary Minstrel Hall |
| Artifice | Alchemist, Artificer | Workshop → Laboratory → Grand Laboratory → Inventor's Sanctum → Artifice Citadel |

## Stronghold Stats

Every stronghold has four stats:

| Stat | Description |
| --- | --- |
| HP | Stronghold health. Reduced by raids and monster events. |
| ATK | Attack power used when your stronghold is raided. |
| DEF | Defense rating. Reduces incoming raid damage. |
| Morale | 0–100. Affects raid outcomes. High morale boosts DEF, low morale weakens it. |

## Commands

| Command | Alias | Description |
| --- | --- | --- |
| `!stronghold` | `!sh` | View your stronghold status |
| `!stronghold build` | `!sh build` | Establish or upgrade your stronghold |
| `!build [room]` | `!br` | Build a room |
| `!gather [material]` | — | Gather raw materials |
| `!visit @username` | `!vs` | Visit another player's stronghold |
| `!raid @username` | — | Raid another player's stronghold |
| `!spy @username` | — | Send spies to gather intel |
